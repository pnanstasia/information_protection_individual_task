## 📝 Опис
Я стоврила модуль, який дозволяє підписувати та перевіряти зображення за допомогою криптографічних підписів, вбудованих у найменш значущі біти (LSB) пікселів зображення.

## 🖥 Використання

### Як запустити аплікацію
1. Скопіювати репозиторій з GitHub
2. Запустити файл з кодом за допомогою команди ***python main.py***
3. Використайте поточне зображення ***image.png*** або завантажте інше зображення формату png.
4. У разі, якщо зображення підписане і підпис ідентифіковано вірно, то вивід програми буде:

Image was signed and saved to the file - signed_image.png
Image was verified, sign is correct

### Результати

При запуску програми створюються пари приватного та публічного RSA ключів. Далі відбуважться хешування зображення – розраховується SHA-256 хеш зображення з очищеними LSB (для стабільності підпису).
Підпис, його довжина та маркер RSSIG кодуються в LSB пікселів. Останній крок - перевірка підпису, я витягую підпис, далі обчислюється хеш зображення, підпис перевіряється за допомогою публічного ключа.

### Використані бібліотеки:

- cryptography — для генерації ключів та цифрового підпису
- hashlib — для хешування зображення
- PIL (Pillow) — для роботи із зображеннями
- numpy — для обробки пікселів зображення
- struct — для збереження довжини підпису у байти

### Структура коду

ImageSigner — головний клас, який містить:
    - generate_keys() — створення RSA ключів
    - sign_image() — створення підпису та вбудовування у зображення
    - verify_signature() — перевірка підпису у зображенні
Внутрішні методи:
    _embed_signature() — вбудовує підпис у зображення
    hash_image() — хешує зображення з очищеними LSB
main() — функція для демонстрації роботи програми

### Обробка помилок

- Якщо зображення замале — підпис не буде вбудовано
- Якщо змінено хоча б 1 піксель підписаного зображення — верифікація не пройде
- Детальні повідомлення про помилки повертаються при зчитуванні некоректного підпису
